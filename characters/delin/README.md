# DELIN — главный герой и команда из 11 AI-агентов

Референсы персонажей для видео (вертикальный ролик ~60 с). Используйте эти файлы как
image-reference, чтобы персонажи выглядели одинаково от кадра к кадру.

## Главный герой — DELIN (басты кейіпкер)

- Подросток/молодой парень, 3D-мультяшный стиль (Pixar-like).
- Взъерошенные светло-русые/золотистые волосы, большие карие глаза, круглые чёрные очки.
- Тёмно-зелёное худи с белыми шнурками, под ним чёрная футболка.
- Окружение: тёплая вечерняя комната — красная настольная лампа, полка с книгами и
  серебряной кнопкой YouTube, лампа-луна, казахский ковёр (красно-синий орнамент) на стене,
  ноутбук, кружка с казахским орнаментом, блокнот, растения.

## Агенты — команда DELIN

Общий дизайн: красный «кирпичик»-персонаж с улыбающимся лицом (чёрные глаза, белая улыбка),
в казахском национальном костюме — расшитый золотом камзол (синий или бордовый) и
тюбетейка/такия с золотым орнаментом либо меховая шапка (бөрік). Красные ручки-перчатки.
У каждого агента свой атрибут и неоновая иконка роли.

### Альтернативный набор ролей (`agents-alt/`)

Со второго листа: Монтажер, Зерттеуші, Дизайнер, Жоспарлаушы, Аналитик, Сценарист,
SMM агент, **Қолдау агенті** (комментарий, жауап), **Автоматтандырушы** (процесті
жеңілдетеді), **Идея генераторы** (жаңа идея ұсынады).
